# TESTE-FUNCTIONALE / FUNCTIONAL-TESTS

FOARTE IMPORTANT ! / VERY IMPORTANT ! 
Pentru ca testele de mai jos sa functioneze, trebuie avute in vedere urmatoarele / In order for the tests below to work, the following must be taken into account : 
- creare cont pe site-ul https://www.mosionroata.ro/   /    create an account on the website https://www.mosionroata.ro/
- pe baza codurilor, este necesara completarea acestora cu informatiile marcate cu "........"   /   based on the codes, it is necessary to complete them with the information marked with "........"
  
Proiectul are in compunere 15 teste automate. / The project consists of 15 automatic tests.

Testele vor fi aplicate sectiunilor afisate in cadrul site-ului ales pentru testare. / The tests will be applied to the sections displayed within the site chosen for testing.

Aceste teste sunt / These tests are:
1.	Test verificare status pagină principală - Acest test va verifica dacă pagina principală a site-ului ales pentru testare este activă și nu returnează un cod de eroare, cel pregonizat fiind 200. / Main page status check test - This test will check if the main page of the site chosen for testing is active and does not return an error code, the predicted one being 200.
2.	Test acceptare cookie-uri pagină principală - Acest test acceptă politica de Cookie a site-ului ales pentru testare. / Main page cookie acceptance test - This test accepts the Cookie policy of the site chosen for testing.
3.	Test scroll pe verticală pagină principală - Acest test va face Scroll pe verticală a paginii principale a site-ului ales pentru testare. / Main page vertical scroll test - This test will make the main page of the chosen site for testing scroll vertically.
4.	Test accesare secțiunea 'DESPRE NOI' - Acest test va accesa secțiunea "DESPRE NOI", prezentă țn cadrul site-ului ales pentru testare și completarea formularului online disponibil. / Test to access the 'DESPRE NOI' section - This test will access the "ABOUT US" section, present within the website chosen for testing and completing the available online form.
5.	Test "Intra pe cont" pe site, în cont de utilizator/client creat în prealabil, verificare secțiuni disponibile, și apoi 'Logout' - În prealabil s-a creat un cont de utilizator/client, necesar ulterior în cadrul altor teste. Acest test va efectua logarea pe contul de utilizator/client, deja creat. / Test "Intra pe cont" on the site, in a previously created user/client account, check the available sections, and then 'Logout' - A user/client account has previously been created, which is later required in other tests. This test will perform the login on the user/customer account, already created.
6.	Test funcționare caseta 'Cauta in site ...' din pagina principală - Acest test va verifica funcționalitatea casetei 'Cauta in site ...' din pagina principală a site-ului ales pentru testare. / Functionality test of the 'Cauta in site ...' box on the main page - This test will check the functionality of the 'Cauta in site ...' box on the main page of the site chosen for testing.
7.	Test cautare produs 1 in caseta 'Cauta in site ...' din pagina principală și finalizare comandă - Acest test va efectua cautarea unui produs în cadrul site-ului ales pentru testare, se va accesa produsul respectiv, se configurează, se adaugă în coș și se finalizează comanda. / Product 1 search test in the 'Cauta in site ...' box on the main page and order completion - This test will search for a product within the site chosen for testing, access the respective product, configure it, add it to cart and complete the order.
8.	Test cautare produs 1 in caseta 'Cauta in site ...' din pagina principală și test cautare produs 2, urmate de finalizare comandă - Acest test va efectua cautarea unui produs în cadrul site-ului ales pentru testare, se va accesa produsul respectiv, se configurează, se adaugă în coș. În continuare se va efectua cautarea unui alt produs în cadrul site-ului ales pentru testare, se va accesa produsul respectiv, se configurează, se adaugă în coș și se finalizează comanda pentru cele doua categorii de produse alese. / Product 1 search test in the 'Cauta in site ...' box on the main page and product 2 search test, followed by order completion - This test will search for a product within the site chosen for testing, the respective product will be accessed, configured, added to cart. Next, the search for another product will be carried out within the site chosen for testing, the respective product will be accessed, configured, added to cart and the order for the two categories of chosen products will be completed.
9.	Test sortare 'Biciclete Mountainbike' din secțiunea 'TOATE PRODUSELE' - Acest test va efectua sortarea produselor 'Biciclete Mountainbike' din secțiunea "TOATE PRODUSELE", în urma aplicării filtrelor dorite, disponibile pe pagina 'Biciclete Mountainbike'. / 'Mountain Bikes' sorting test from the 'TOATE PRODUSELE' section - This test will sort the 'Mountain Bikes' products from the 'TOATE PRODUSELE' section, after applying the desired filters, available on the 'Mountain Bikes' page.
10.	Test accesare secțiunea 'BLOG' - Acest test va efectua accesarea secțiunii "BLOG", secțiune prezenta in cadrul site-ului ales pentru testare. / Test accessing the 'BLOG' section - This test will access the "BLOG" section, the section present within the site chosen for testing.
11.	Test accesare secțiunea "BRANDURI" - Acest test va prezenta lista brand-urilor comercializate de către site-ul ales pentru testare, în ordinea numărului de pagini disponibile in această secțiune a site-ului. / Test accessing the "BRANDURI" section - This test will present the list of brands sold by the site chosen for testing, in order of the number of pages available in this section of the site.
12.	Test accesare secțiunea "RETUR/GARANTIE" și completare Formular de Retur - Acest test va efectua accesarea și completarea formularului online cu privire la returnarea unui produs nou comandat online, produs care la primire, prezintă urme de uzura. / Test to access the "RETUR/GARANTIE" section and fill in the Return Form - This test will access and fill in the online form regarding the return of a new product ordered online, product that, upon receipt, shows signs of wear.
13.	Test accesare secțiunea "RETUR/GARANTIE" si completare Formular de Garantie - Acest test va efectua accesarea și completarea formularului online cu privire la aplicarea condițiilor de garanție comerciala asupra unui produs nou, puțin utilizat, care prezintă diverse neconcordanțe funcționale și de formă. / Test to access the "RETUR/GARANTIE" section and complete the Warranty Form - This test will access and complete the online form regarding the application of the commercial warranty conditions on a new, little-used product, which presents various functional and form inconsistencies.
14.	Test accesare secțiunea "CONTACT" - Acest test va efectua accesarea secțiunii "CONTACT", secțiune prezentă în cadrul site-ului ales pentru testare și completarea formularului on-line disponibil. / Test to access the "CONTACT" section - This test will access the "CONTACT" section, the section present in the site chosen for testing and filling out the available online form.
15.	Test abonare la "Newsletter" - Acest test va efectua abonarea la "Newsletter", secțiune prezentă în cadrul site-ului ales pentru testare. / Test subscription to "Newsletter" - This test will perform the subscription to "Newsletter", a section present within the site chosen for testing.
    
În cadrul unora dintre teste s-a optat pentru similaritate cu celelalte, pentru a se evidenția ceea ce se dorește a se prezenta prin intermediul respectivului test, într-o maniera cursivă și logică. Fiecare dintre teste are în compunere și assert-uri pentru diferite componente ale site-ului respectiv, presupus a fi aplicate. / In some of the tests, we opted for similarity with the others, in order to highlight what is intended to be presented through that test, in a cursive and logical manner. Each of the tests also contains assertions for different components of the respective site, supposed to be applied.
